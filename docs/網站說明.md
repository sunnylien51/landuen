## 10. 可編修資料一覽（config.php）

之後後台可編修的範圍（現況皆在 config）：

1. `siteName`／`siteDescription` — 站名、描述
2. `homeHeroCopy` — 首頁主視覺文案（標題／副標／說明，全輪播共用）
3. `homeHeroSlides` — 首頁主視覺圖（桌機 src／手機 srcMb）＋ alt
4. `homeOem` — 首頁 OEM｜ODM｜OBM（區塊標題／說明＋三軌＋大圖／影片區文案與檔案）
5. `partners`／`homePartnersLimit` — 戰略夥伴（含 showOnHome；首頁最多 18 筆）
6. `knowledgeArticles` — 床墊知識列表欄位（標題／摘要／圖／slug；內文仍在各篇 HTML）
7. `materialSystems` — 六大材料系統（標題／說明／細項／圖／PDF）
8. `aboutPillars` — 四大核心支柱（標題／簡介／圖／連結）
9. `footerCta` — 頁尾 CTA（標題／說明／按鈕文案）

其餘寫在 HTML／Blade 的文案與圖路徑＝**固定文字內容**。

## 12. 本地預覽與上線

1. `composer install`、`npm install`
2. 預覽：`npm run serve`（另開終端執行 `npm run dev` 打包前端）
3. 建置：`npm run build`
4. 上線目錄：`build_production/`（見 `netlify.toml`）
